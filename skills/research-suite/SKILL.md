# 科研套件入口

讀取[科研分工](../codex-research/references/pstack-integration.md)與 [Pstack 入口](../poteto-mode/SKILL.md)。同一任務已讀則沿用。

以科研分工表選擇需要的技能，再讀取該技能原文。不要因安裝套件而載入或執行全部 65 個 skills，也不另建一套重複的研究紀錄。

科研技能負責方法和證據；Pstack 處理任務需要的工程執行。多輪研究才讀取 [RSI 思路](../rsi-anything/SKILL.md)，預設不部署模型、不啟動官方框架。實際需要 RSI 實作時再查其執行參考，遵循當次授權與資源限制。

優先使用本插件內的相對連結。以此儲存庫為維護主來源，不從全域散裝 skills 匯回內容。此包不攜帶 Python 環境、第三方 MCP、模型或憑證；依科研分工文件先檢查主機能力。
