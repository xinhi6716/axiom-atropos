# Compatibility

The native runtime retains plugin ID `axiom-forge`, 66 skills, eight MCP tool names, original SQLite entries and orchestration file formats. Codex/Claude install through their CLIs. DeepSeek Harness, Antigravity and Pi use managed skill directories.

Windows x86-64 and Linux x86-64 are the release targets. Core installation, bridge, memory and bookkeeping do not require an interpreter. Optional upstream scientific, watcher, shell and TLC companions retain their own dependencies. See [migration boundary and commands](rust-runtime.md).

CI validates native behavior and scripted backend contracts. Host registration arguments are tested with a native fake CLI; this is not vendor certification or proof of access to a paid model account. A prior installed plugin is not changed until the user invokes the new installer.
